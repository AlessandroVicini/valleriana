# Signori della Valleriana

Gioco di strategia a turni stagionali ispirato a *Lords of the Realm II*, ambientato nelle dieci castella della Valleriana (Pescia, Toscana) tra Duecento e Trecento.

**Gioca:** https://alessandrovicini.github.io/valleriana/

Su Android: apri il link con Chrome, menu ⋮ → *Installa app*. Dopo la prima apertura funziona anche offline.

## Aggiornare il gioco
1. Sostituisci `index.html` (Add file → Upload files).
2. In `sw.js` aumenta il numero di `VERSIONE` (`valleriana-v2`, `v3`…), altrimenti i telefoni continuano a usare la copia vecchia.
